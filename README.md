# 212 Cleaning

Next.js + TypeScript commercial cleaning website. App root: `website`.

## Develop

```sh
cd website
npm install
npm run dev
```

## Check

```sh
npm run typecheck
npm run build
```

## Railway

Set service Root Directory to `/website`. Build: `npm run build`. Start: `npm run start`. Railway provides PORT.

## Before public launch

Confirm business services, coverage, company name, contact details and specialty capabilities. Contact route intentionally does not collect submissions until a real backend is connected. No database or customer data is currently stored.
